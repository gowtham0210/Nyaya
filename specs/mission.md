# Nyaya Mission and Product Constitution

Last updated: 2026-04-26
Source: `specs/Nyaya Quiz App User Flow.png`

## Mission

Nyaya exists to help law learners move from curiosity to exam-ready confidence
through short, guided learning loops. The app should make it easy to start,
understand legal concepts, practice with focused quizzes, review mistakes, and
build steady study momentum over time.

## Primary User Promise

Nyaya shall help a user:

- understand what to study for a chosen goal and exam track
- convert legal concepts into actionable quiz practice
- receive immediate feedback on answers
- revisit weak areas with targeted repetition
- retain useful explanations through notes and bookmarks
- stay motivated through visible progress, streaks, and badges

## Core User Journey

The app flow establishes six core journeys:

1. Activation journey: `Splash -> Onboarding -> Create Account/Login -> Choose Goal and Exam Track`
2. Navigation journey: `Home / Learning Path -> Bottom Navigation`
3. Quiz journey: `Select Law Topic -> Topic Detail -> Start Quiz -> Quiz Question -> Instant Feedback -> Result Summary -> Review Answers and Explanations`
4. Reinforcement journey: `Review -> Retry Weak Questions -> Quiz`
5. Learn journey: `Nyaya AI / Learn -> Ask Legal Concept Question -> AI Explanation with Related Quiz`
6. Retention journey: `Save Notes -> Notes / Bookmarks` and `Profile -> Streaks, Badges, Settings`

## Product Constitution

### 1. Start With Clarity

The first-run experience must explain why Nyaya exists, how learning works, and
why the user should trust the app before asking for commitment.

### 2. Personalize Early

Goal and exam-track selection are foundational. Nyaya must adapt learning paths,
topic framing, and quiz relevance to the user’s chosen direction as early as
possible.

### 3. Always Offer a Next Action

After login, onboarding, a quiz, an explanation, or a review, the app must
present one clear next step so users never stall inside the flow.

### 4. Learning Happens Through Retrieval

Quiz practice is not a side feature. It is a central learning mechanic. Users
must be able to move from topic discovery to question practice with minimal
friction.

### 5. Feedback Must Be Immediate and Educational

Every answered question should produce immediate correctness feedback, and the
post-quiz review must explain what happened so mistakes become learning
opportunities.

### 6. Weak Areas Must Return to the Surface

Nyaya must make it easy to revisit weak questions and difficult topics. Review
history should feed future study actions instead of ending at a static result
screen.

### 7. AI Must Lead Back to Practice

The Learn experience should not stop at explanation. AI responses should point
the user toward related quiz practice so conceptual learning and active recall
stay connected.

### 8. Useful Learning Artifacts Must Persist

Notes and bookmarks are part of the learning loop. Users must be able to save,
revisit, and use them later during review and practice.

### 9. Motivation Must Reflect Real Progress

Streaks, badges, and profile metrics should reinforce actual study behavior and
learning consistency, not distract from the core study loop.

### 10. Settings Must Respect the User’s Study Context

Goal, language, and notification settings should support the study plan rather
than behave like generic profile controls.

## Experience Boundaries

Nyaya is primarily a guided legal learning and quiz product. Based on the flow,
the current product direction does not center on:

- social feeds or community discussion
- multiplayer competition
- unrelated productivity tools
- broad content browsing without a learning goal

## Product Success Signals

The flow implies that Nyaya is succeeding when users can:

- complete onboarding and reach a personalized home path
- start quizzes from both topic exploration and AI-assisted learning
- finish a quiz and review explanations without dropping out
- retry weak questions instead of ending after one attempt
- save notes and return to them later
- build visible streak and badge progress over repeated sessions
